# SQL-Project-Consumer-Goods--Ad-hoc-Insights
### 📊 Consumer Goods Ad Hoc Insights — SQL Analytics Project

This project is based on the **Codebasics SQL Challenge** featuring Atliq Hardware's dataset.

> 10 SQL-driven business questions answered with data, charts, and actionable insights for Atliq Hardware's Consumer Goods Division.

---

##  Project Background

Atliq Hardware's management identified a critical gap in their ability to make quick, data-driven decisions. To address this, the Director of Data Analytics, **Tony Sharma**, designed a SQL challenge to evaluate junior data analyst candidates on both technical expertise and communication skills.

This project is my response to that challenge — analyzing Atliq Hardware's sales, product, and customer data to surface insights that directly support strategic decision-making.

##  Key Strategic Insights

- **APAC footprint** — Atliq Exclusive is active in 8 markets, showing strong regional reach.
- **Product portfolio grew 36%** in FY2021, led by Accessories segment (+34 SKUs).
- **November is consistently the peak sales month** — festive season (Diwali/Navratri) drives demand. Inventory must be planned early.
- **Retailers account for 73% of revenue** — Direct and Distributor channels need strategic investment.
- **N&S division leads in volume** (700K+ units); the PC division has a 40x gap and needs a strategic review.
- **COVID-19 impact** was severe in Mar–Aug 2020 with sales as low as $0.38M in March.
